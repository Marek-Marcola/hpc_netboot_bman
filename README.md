netboot bman
============

HPC netboot management tools.

Install
-------
Install:

    bman.sh -inst -x
    -- or --
    bman.sh -anpb -x
    -- or --
    cp -fv bman.sh /usr/local/bin
    cp -fv bman.env /usr/local/etc
    cp -fv zlocal-bman.sh /etc/profile.d

Verify:

    bm -ver

Help:

    bm -h
